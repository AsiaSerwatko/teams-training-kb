# Create a class team for a training group

Each training group gets its own team in Microsoft Teams. You schedule the group's sessions in this team, and Teams saves the session recordings in the team's files.

**Applies to:** Microsoft Teams (desktop and web) in Microsoft 365 Education organizations  
**Time needed:** about 5 minutes

## Before you begin

- Trainers you want to add to the team must already have an account in your organization. See [Add a trainer to your Microsoft 365 organization](01-add-trainer-to-organization.md).
- The **Class** team type is available only in Microsoft 365 Education organizations.

## Create the team

1. In Teams, select **Teams** in the left bar.
2. Select **Join or create a team**, and then select **Create team**. In the new Teams, use the **+** icon at the top of your team list.
   <!-- Screenshot: Join or create a team > Create team -->

   > [!NOTE]
   > In some versions of Teams, the **Create team** button appears only when you hover over its tile.

3. Select the **Class** team type.
4. Enter a name for the team. A description is optional. Select **Next**.

   > [!TIP]
   > Use the same naming pattern for every group, for example *Course name – Group – Start date*. It makes teams easy to find in long lists and in search.

5. Add teachers. For each group, add the program coordinators and the trainer or trainers who lead the classes. You can select several people at once. Select **Add**.
   <!-- Screenshot: Add teachers dialog with several people selected -->
6. The new team appears in your team list.

## Change the team picture (optional)

A recognizable picture helps participants who belong to several teams find the right one.

1. Next to the team name, select **More options (...)** > **Edit team**.
2. Choose one of the available pictures or upload your own.
   <!-- Screenshot: Edit team > team picture -->

> [!TIP]
> Upload pictures in JPG format. PNG files sometimes fail to upload.
