# Running live training in Microsoft Teams

A short knowledge base for training coordinators who run live online courses in Microsoft Teams: from adding a new trainer to sharing session recordings with participants.

Follow the articles in order the first time you set up a group. Later, use them as a reference.

| # | Article | Who it's for |

| 2 | [Create a class team for a training group](02-create-class-team.md) | Coordinators |
| 3 | [Schedule class sessions and set meeting options](03-schedule-class-sessions.md) | Coordinators |
| 4 | [Create a view-only folder for participants in OneDrive](04-create-shared-folder.md) | Coordinators |
| 5 | [Share class recordings with participants](05-share-recordings.md) | Coordinators |

## About this project

I adapted these articles from an internal Polish guide that I wrote for my team. Names, links and organization details have been removed. Microsoft updates the Teams interface regularly, so some labels may differ slightly in your version.
