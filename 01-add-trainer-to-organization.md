# Add a trainer to your Microsoft 365 organization

Trainers need an account in your Microsoft 365 organization before you can add them to a class team or make them co-organizers of class meetings. This article shows how to create that account in the Microsoft 365 admin center by using a user template.

**Applies to:** Microsoft 365 admin center  
**Time needed:** about 5 minutes

## Before you begin

- You need an admin role that lets you add users, such as User Administrator or Global Administrator.
- Check that you have a free license for the new account.
- This article uses a user template named **Trainers**. A user template stores the settings that every trainer account needs, such as licenses and apps, so you don't have to set them up each time. If your organization doesn't have this template yet, create it first: go to **Users** > **Active users** > **User templates** > **Add template**.

## Add the trainer

1. Sign in to the Microsoft 365 admin center at [admin.microsoft.com](https://admin.microsoft.com).
2. In the left menu, select **Users** > **Active users**.
   <!-- Screenshot: Users > Active users in the left menu -->
3. At the top of the page, select **User templates**, and then select **Trainers**.
   <!-- Screenshot: User templates menu with the Trainers template -->
4. Enter the trainer's details, such as first name, last name and username.
5. In the password settings, select the option to send the password by email, and enter the trainer's email address.
6. Review the details, and then select **Add user**.
   <!-- Screenshot: Add user form with the email option selected -->

> [!IMPORTANT]
> Tell the trainer about the new account **before** the automatic email arrives, and explain why they need it: without an account in your organization, they can't be co-organizers of class meetings. An unexpected sign-in email from an unknown organization can look like phishing.
