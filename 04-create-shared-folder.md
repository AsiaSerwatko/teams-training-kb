# Create a view-only folder for participants in OneDrive

Participants get session recordings and materials from a folder in your OneDrive. Share the folder as view-only and block downloads, so that course materials stay with the group.

**Applies to:** OneDrive for work or school (web)  
**Time needed:** about 5 minutes per group

## Create the folder

1. Open OneDrive for work or school in your browser.
2. Select **+ Add new** (or **+ New**), and then select **Folder**.
   <!-- Screenshot: + Add new > Folder -->
3. Enter a name for the folder, for example the name of the group's team, and select **Create**.

## Share the folder as view-only

1. Hover over the folder and select the **Share** icon.
2. In the sharing dialog, select the current link setting to open **Link settings**.
   <!-- Screenshot: sharing dialog with the link setting highlighted -->
3. Choose who the link works for, as your organization's sharing policy allows.
4. Under permissions, select **Can view**.
5. Turn on **Block download**.
6. Select **Apply**. The sharing dialog now shows the new link description.
7. Select **Copy link**, and send the link to the participants.
   <!-- Screenshot: link settings with Can view and Block download -->

> [!IMPORTANT]
> Copy the link before you close the sharing dialog. If you close it without copying, the new link settings might not be saved.

## Troubleshooting

**A participant says the link doesn't open.**
Copy the link a second way: next to the folder, select **More options (...)** > **Copy link**. The two links differ only by a parameter at the end, and if one doesn't work, the other usually does. To avoid a round of support questions, send participants both links from the start.
