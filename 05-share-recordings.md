# Share class recordings with participants

Teams saves the recordings of channel meetings in a **Recordings** folder in the channel's files. Participants share recordings through your OneDrive folder, so copy each new recording there after the session.

**Applies to:** Microsoft Teams, OneDrive for work or school  
**Time needed:** about 2 minutes per session

## Before you begin

- The group has a view-only shared folder. See [Create a view-only folder for participants in OneDrive](04-create-shared-folder.md).

## Copy recordings to the shared folder

1. In Teams, open the group's team. In the **General** channel, select the **Files** tab.
   <!-- Screenshot: Posts and Files tabs in the General channel -->
2. Open the **Recordings** folder.
3. Select the recording or recordings you want to share.
4. At the top of the page, select **More options (...)** > **Copy to**.
   <!-- Screenshot: More options > Copy to -->
5. Select **My files**, open the group's shared folder, and then select **Copy here**.
6. Wait for the confirmation message. Participants can now watch the recording through the link you sent them, with the same view-only settings as the folder.

> [!NOTE]
> Copying leaves the original recording in the team's files, so trainers and coordinators can still find it there.

## Troubleshooting

**The team has no Recordings folder.**
Teams creates the folder after the first recording in a channel. If a session was recorded but the folder still doesn't appear, the recording wasn't saved to the channel's files. Do the following instead:

1. In the **General** channel, select the **Posts** tab and find the recording in the meeting thread.
2. Download the recording to your computer.
3. Open the shared folder in OneDrive and drag the file into the browser window, or select **Upload**.
